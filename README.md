# CodeEditorBracketChecker
Ask the user to paste in a line of code, then check whether the brackets ()[]{} in it are properly nested and closed, printing True or False.
<br>
Topics covered:
input(),
Variables,
for loop,
if / elif,
Lists,
append(),
pop(),
Dictionary,
Dictionary key-value,
Membership operator — in,
not,
Indexing — stack[-1],
Boolean — True / False,
break,
else with for loop.
<br>
Main concept:
👉 Stack data structure + Lists + Dictionary + Conditions
